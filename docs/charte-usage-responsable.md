# Charte d'usage responsable

Module *Cybersécurité orientée Dev / Data / IA* - IRIS Mediaschool Montpellier · Humanix Cybersecurity

En signant cette charte, l'étudiant s'engage à :

1. **Limiter toute technique offensive aux environnements fournis et isolés** de ce module
   (conteneurs Docker locaux, OWASP Juice Shop, CTF de l'intervenant).
2. **Ne mener aucun test** sur des systèmes tiers, en production, ou sans autorisation écrite
   explicite du propriétaire.
3. **Respecter le cadre légal** : les atteintes aux systèmes de traitement automatisé de données
   sont réprimées par les **articles 323-1 et suivants du Code pénal**.
4. **Ne pas diffuser** les vulnérabilités ou données obtenues pendant le module en dehors du cadre
   pédagogique.
5. **Adopter une finalité strictement défensive** : comprendre l'attaque pour mieux protéger.

> Le non-respect de cette charte peut entraîner l'exclusion du module et des poursuites.
